# رابط خط فرمان پراپ (Prop CLI)

رابط خط فرمان پراپ، سبک‌ترین و سریع‌ترین راهکار برای ارتباط مستقیم با ایجنت‌های هوشمند در محیط ترمینال است. بدون جابجایی بین پنجره‌ها، وظایف برنامه‌نویسی و پردازش داده را از کیبورد خود هدایت کنید.

### نصب سریع
```bash
# برای مک و لینوکس:
curl -fsSL https://prop-ai.ir/cli/install.sh | bash

# برای ویندوز (PowerShell):
irm https://prop-ai.ir/cli/install.ps1 | iex
```

### کاربردها
* هدایت ایجنت در پوشه کاری جاری
* رفع خطاها و باگ‌ها به صورت خودکار
* اجرای دستورات شل با تایید مرحله‌ای
